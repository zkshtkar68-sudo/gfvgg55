# هوم‌لندر — نمونه اولیه دستیار صوتی فارسی اندروید

## وضعیت این نسخه
این پروژه یک نمونه اولیه قابل توسعه است. قابلیت‌های موجود:
- رابط فارسی و راست‌چین‌پسند
- تشخیص گفتار با تنظیم زبان `fa-IR` از سرویس گفتار نصب‌شده روی گوشی
- پاسخ صوتی با Android TextToSpeech، در صورت وجود موتور/داده صدای فارسی
- بازکردن مرورگر و یوتیوب در صورت نصب
- بازکردن صفحه شماره‌گیری برای تماس (کاربر تماس را تأیید می‌کند)
- آماده‌کردن پیامک در برنامه پیامک (کاربر ارسال را تأیید می‌کند)
- پاسخ به چند فرمان ساده و اعلام ساعت

## پیش‌نیازها
- Android Studio نسخه‌ای که Android Gradle Plugin 8.7.3 و Gradle سازگار را پشتیبانی کند
- JDK 17
- Android SDK Platform 35
- گوشی Android 8.0 (API 26) یا بالاتر یا شبیه‌ساز
- برای تشخیص گفتار، سرویس Speech Recognition نصب و فعال باشد؛ ممکن است اینترنت لازم باشد
- برای صدای فارسی، موتور TTS گوشی باید زبان فارسی را پشتیبانی کند و داده آن نصب باشد

## باز کردن پروژه
1. فایل ZIP را استخراج کن.
2. Android Studio را باز کن و `Open` را بزن.
3. پوشه `HomelanderAndroid` را انتخاب کن.
4. منتظر بمان Gradle Sync تمام شود.
5. گوشی را با USB debugging وصل کن یا شبیه‌ساز اجرا کن.
6. روی Run بزن.
7. برای ساخت APK آزمایشی: `Build > Build APK(s)`.
   معمولاً خروجی در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## فرمان‌های نمونه
- «مرورگر را باز کن»
- «یوتیوب را باز کن»
- «سلام»
- «ساعت چنده؟»
- «با شماره 09123456789 تماس بگیر»
- «به شماره 09123456789 پیام بده سلام»

## محدودیت‌ها و گام بعدی
- این نسخه هنوز مدل گفت‌وگوی هوش مصنوعی آنلاین ندارد؛ برای پاسخ آزاد به پرسش‌ها باید یک سرویس AI و کلید API به‌صورت امن اضافه شود.
- کیفیت تشخیص و صدای فارسی به سرویس‌ها و داده‌های نصب‌شده روی گوشی بستگی دارد.
- مکالمه پیوسته و بدون لمس، wake word، اجرای مطمئن در پس‌زمینه، خواندن پیام‌های پیام‌رسان‌ها و کنترل تنظیمات حساس گوشی در این MVP پیاده نشده‌اند.
- برنامه عمداً مستقیماً تماس را برقرار نمی‌کند و پیامک را بدون تأیید نمی‌فرستد.
- قبل از انتشار عمومی، تست روی چند گوشی، رسیدگی به خطاها، حریم خصوصی و امنیت API ضروری است.
